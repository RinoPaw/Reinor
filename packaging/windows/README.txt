Reinor temporary support, Windows 10/11 x64
==============================================

1. Obtain this archive from the Releases page of RinoPaw/Reinor on GitHub.
2. Extract the whole ZIP. Do not run the executable as Administrator.
3. Double-click Start-Temporary-Support.cmd.
4. Give the approved operator your Request ID (join_...). Never share the private ticket or passwords.
5. Verify the operator and scope of work before they approve the session.
6. Keep the console window open while you consent to assistance. Close it to disconnect.

The temporary Agent does not install a startup service, write an enrollment credential,
or automatically reconnect. The Gateway enforces a short approval window and a
bounded session lifetime. Operator should revoke the request when work finishes.

The operator can execute commands with your logged-in Windows user's privileges.
Close unrelated private documents before running the Agent.
The Gateway defaults to https://xuhuaai.top and uses an outbound encrypted WebSocket.
Do not bypass antivirus warnings without verifying the release publisher and checksum.
